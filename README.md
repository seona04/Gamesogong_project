# Gamesogong_project

`파도 끝의 집`의 첫 번째 월드 프로토타입입니다. Visual Studio 2022용 C++17 콘솔 프로젝트로, 해무섬의 장소와 이동 경로를 코드로 생성합니다.

## 구현된 월드 공간

- **부모님의 집**: 주인공의 시작 위치. 집과 정원이 있는 언덕입니다.
- **해무 포구**: 주민과 시장이 모이는 섬의 중심입니다.
- **솔숲길**: 집과 마을을 잇는 숲길입니다.
- **물비늘 갯벌**: 조개와 작은 바다 생물을 찾을 수 있으며, 간조에만 길이 열립니다.
- **바람곶**: 오래된 등대가 있는 절벽입니다.

각 장소에는 지도 좌표가 있고, 장소 간 경로는 양방향 연결로 관리됩니다. 현재 물때는 간조, 들물, 만조, 날물 순서로 진행합니다. 지도 메뉴는 장소와 경로를 ASCII 지도로 표시하고, 이동 메뉴는 현재 물때에 통행할 수 있는지 알려줍니다.

## Visual Studio에서 실행

1. `Gamesogong_project.sln`을 Visual Studio 2022에서 엽니다.
2. 플랫폼을 `x64`로 선택합니다.
3. `Gamesogong_project`를 시작 프로젝트로 지정하고 `Ctrl+F5`로 실행합니다.

현재 단계는 월드 구조와 이동 규칙을 구현한 콘솔 프로토타입입니다. 이후 낚시, 시장 거래, 정원 시스템과 그래픽 엔진을 이 월드 데이터 위에 추가할 수 있습니다.
