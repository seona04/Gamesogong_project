# Gamesogong_project

**파도 끝의 집**은 해무섬에서 부모님의 흔적을 따라 살아가는 2D RPG 프로토타입입니다. Visual Studio 18, C++17, Win32/GDI로 만들었으며 외부 그래픽 라이브러리 없이 Windows SDK에서 실행됩니다.

## 월드

- **청람 군도 · 해무섬 지도**: 부모님의 집, 해무 포구, 솔숲길, 달빛강, 물비늘 갯벌, 바람곶을 연결합니다.
- **부모님의 집과 정원**: 붉은 기와와 나무 벽의 집, 앞마당 길, 울타리, 나무, 화단과 살림살이를 둘러봅니다. 집 외관과 실내는 서로 다른 플레이 장면입니다.
- **부모님의 집 실내**: 오래된 침대와 장롱, 화로, 식탁, 부모님의 물때 기록장이 있는 따뜻한 실내입니다.
- **달빛강**: 솔숲에서 흘러온 강변에서 은어, 무늬송어, 은빛 잉어를 낚습니다.
- **해무 앞바다**: 모래 해변과 나무 부두에서 전갱이, 참돔, 고등어를 낚습니다.

월드와 물결은 GDI 도형으로 직접 그린 오리지널 프로토타입입니다. 첨부된 게임 이미지는 낚시 화면의 배치와 분위기를 참고하는 용도로만 사용했습니다.

## Visual Studio에서 실행

1. Gamesogong_project.sln을 Visual Studio 18에서 엽니다.
2. 구성은 Release, 플랫폼은 x64로 선택합니다.
3. Gamesogong_project를 시작 프로젝트로 지정하고 Ctrl+F5로 실행합니다.

## 조작

### 섬 지도

- 방향키 또는 WASD: 연결된 장소로 이동
- Space: 다음 물때로 진행
- Enter: 장소에 들어가기. 부모님의 집은 정원, 달빛강은 강 낚시, 해무 포구와 물비늘 갯벌은 바다 낚시 장면으로 이동
- Esc: 지도에서 게임 종료

달빛강은 섬 지도에서 솔숲길로 이동한 다음 위쪽으로 이동하면 찾을 수 있습니다. 바다는 해무 포구에서 Enter를 눌러 들어갑니다.

### 강과 바다 낚시

- 방향키 또는 WASD: 물가 이동
- 물 위를 마우스 왼쪽 클릭: 낚싯대 던지기
- 찌가 흔들릴 때 왼쪽 클릭: 입질에 맞춰 물고기 걸기
- 물고기가 걸린 뒤 왼쪽 클릭: 릴 감기
- 물고기가 걸린 뒤 오른쪽 클릭: 줄 장력 낮추기
- M 또는 Esc: 섬 지도

낚은 민물고기와 바닷물고기는 화면의 어획 기록에 각각 집계됩니다. 낚시에는 키보드 상호작용 키가 필요하지 않습니다.

### 정원과 집 외관

- 방향키 또는 WASD: 정원 이동
- 부서진 울타리 가까이에서 R: 울타리 수리
- 빈 화단 가까이에서 F: 부모님의 꽃 심기
- 현관 계단 가까이에서 E 또는 Enter: 실내로 들어가기
- M 또는 Esc: 섬 지도

### 집 실내

- 방향키 또는 WASD: 실내 이동
- 식탁 가까이에서 E 또는 Enter: 부모님의 물때 기록장 읽기
- 현관 가까이에서 E 또는 Enter, 또는 Esc: 정원으로 나가기

## 현재 구현 범위

섬 지도와 장소 이동, 물때 변화, 집 외관·정원과 실내, 강·바다 낚시 장면을 구현했습니다. 정원의 울타리 수리·꽃 심기, 낚시와 어획 집계는 현재 실행 중에만 유지됩니다. 다음 단계에서는 어획물을 시장에 판매하고 받은 보수로 집을 수리하거나 꾸미는 기능을 연결할 수 있습니다.
