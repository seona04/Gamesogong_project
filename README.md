# Gamesogong_project

`파도 끝의 집`의 2D 월드 탐험 프로토타입입니다. Visual Studio 18과 C++17로 만든 Win32/GDI 창에서 해무섬을 위에서 내려다보는 지도 형태로 보여줍니다. 외부 그래픽 라이브러리 없이 Windows SDK만 사용합니다.

## 화면에 생성되는 월드

- **부모님의 집**: 언덕 위 집과 작은 정원
- **해무 포구**: 부두와 새벽 시장
- **솔숲길**: 소나무 숲과 정원 재료를 찾는 길
- **물비늘 갯벌**: 물길과 조개가 있는 갯벌. 간조에만 이동 가능
- **바람곶**: 절벽과 오래된 등대

섬의 지형, 장소 그림, 이동 경로는 GDI 도형으로 그립니다. 장소 데이터와 양방향 경로는 `World` 클래스에서 관리하며, 물때는 간조 → 들물 → 만조 → 날물 순으로 바뀝니다.

## Visual Studio에서 실행

1. `Gamesogong_project.sln`을 Visual Studio 18에서 엽니다.
2. 구성은 `Release`, 플랫폼은 `x64`로 선택합니다.
3. `Gamesogong_project`를 시작 프로젝트로 지정하고 `Ctrl+F5`로 실행합니다.

## 조작

- 방향키 또는 `WASD`: 연결된 장소로 이동
- `Space`: 다음 물때로 진행
- `Enter`: 현재 장소 살펴보기
- `Esc`: 게임 종료

현재 단계는 월드 화면과 장소 이동 프로토타입입니다. 다음에는 낚시, 시장 거래, 정원 가꾸기와 인물 대화를 연결할 수 있습니다.
